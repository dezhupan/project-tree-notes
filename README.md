# Project Chinese Notes

在 PyCharm“项目”视图的文件和目录名称右侧显示中文说明，适合阅读陌生项目、教学项目和缩写较多的代码仓库。

## 当前版本

- 版本：`1.0.6`
- 兼容：PyCharm Professional 2026.1.x（内部版本 `261.*`）
- 安装包：`project-tree-notes-1.0.6.zip`
- 系统：Windows、macOS、Linux

## 主要功能

- 为项目、目录和文件手动添加中文说明。
- 将全部说明保存在项目根目录的 `project_notes.tree.tsv` 中，便于查看和编辑。
- 可选择文件或目录，通过兼容 OpenAI 的接口批量生成 2–8 个字符的中文标签。
- AI 结果先预览，确认后才写入。
- 支持撤销最近一次 AI 批量生成。
- 可一键清空全部说明，但不会删除项目文件、目录或路径记录。

## 安装方法

1. 下载 `project-tree-notes-1.0.6.zip`，不要解压。
2. 打开 PyCharm，进入 `Settings → Plugins`。
3. 点击齿轮按钮，选择 `Install Plugin from Disk...`。
4. 选择 ZIP，按提示完成安装或重启。

## 基本使用

在 PyCharm“项目”视图中右键文件或目录，打开“项目中文说明”菜单，即可编辑说明、AI 生成标签、撤销生成、清除说明或打开说明表。

普通说明功能完全离线。API Key 使用 PyCharm 密码库保存，不写入项目或发布包；只有主动执行 AI 生成功能时才会访问配置的接口。

更完整的操作方法和故障排查见 [使用说明.md](使用说明.md)。

## 仓库内容

仓库包含插件源码、测试、构建脚本和当前可直接安装的 ZIP；生成的 `build/` 目录及历史发行包不纳入主分支。
